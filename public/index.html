API Documentation

Endpoint schemas, Basic Authentication, and Mongoose Data Models

Security: Basic Authentication

All /api/users endpoints are protected with standard HTTP Basic Authentication.

Authorization: Basic YWRtaW46YWRtaW4xMjM=

Default credentials: admin / admin123 (or any registered user email + password).

Mongoose User Schema

name: String (Required, 2-100 chars)
email: String (Required, Unique, Valid Email)
password: String (Hashed with bcryptjs, hidden by default)
role: String ('user' | 'admin' | 'manager')
status: String ('active' | 'inactive' | 'pending')
department: String
phone: String
bio: String

REST API Endpoints Overview

Method Endpoint Auth Required Description
GET /api/users Basic Auth Fetch all users (Supports ?search= & ?role= & ?page=)
POST /api/users Basic Auth Create a new user record
GET /api/users/:id Basic Auth Get specific user by ID
PUT /api/users/:id Basic Auth Update user fields by ID
DELETE /api/users/:id Basic Auth Delete user by ID
POST /api/users/seed Basic Auth Populate 5 sample users
GET /api/users/stats/summary Basic Auth Get database summary statistics
